# Traindata_Qingtian

Auto generate training data for our Qingtian, from existing PoCs.

The `traindata/` skill ships everything it needs: the schema validator, the
anti-shortcut diversity audit, a welded email library (normal free mail,
invented corporate domains, disposable/toxic domains, abuse contacts) and a
compositional name/role vocabulary for generating email local parts.

put out a fire with a sealed box of fire extinguishers. (也因为我白嫖了 CCNC 的拼音库，被传染了，索性大家一起开源吧)。

| project | used for | licence |
